# Verba - Automatic Text Summarizer

**SDG 4: Quality Education**

Verba is an easy-to-use tool designed to summarize lengthy documents and articles quickly, saving time and improving reading efficiency.

## Live Demo
[Open Text Summarizer](https://text-summarizer-g5rgtdmuk5jg5npvccvdq7.streamlit.app/)

## Features
- Paste text or upload TXT, DOCX, and PDF files.
- Generate summaries with adjustable length.
- Copy or download summaries.
- View summary statistics.

## Algorithms Used
1. **Hash Map:** Counts word frequencies using `Counter`.
2. **Priority Queue:** Ranks sentences using `heapq`.
3. **Dynamic Programming (LCS):** Identifies similar sentences to help reduce redundancy.

## Technologies
Python, Streamlit, Hash Maps, Heaps, and Dynamic Programming.
